# ActionSummary

Represents a minimal summary of an action.

## Example Usage

```typescript
import { ActionSummary } from "@gleanwork/api-client/models/components";

let value: ActionSummary = {
  tool_id: "<id>",
  display_name: "Sean71",
};
```
