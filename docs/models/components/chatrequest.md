# ChatRequest

The minimal set of fields that form a chat request.

## Example Usage

```typescript
import { ChatRequest } from "@gleanwork/api-client/models/components";

let value: ChatRequest = {
  messages: [],
  timeoutMillis: 30000,
};
```
