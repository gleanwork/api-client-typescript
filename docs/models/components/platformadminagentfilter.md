# PlatformAdminAgentFilter

A filter on one agent field.

## Example Usage

```typescript
import { PlatformAdminAgentFilter } from "@gleanwork/api-client/models/components";

let value: PlatformAdminAgentFilter = {
  field: "<value>",
  values: [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
};
```
