# PlatformDepartmentFilter

A filter on one department field.

## Example Usage

```typescript
import { PlatformDepartmentFilter } from "@gleanwork/api-client/models/components";

let value: PlatformDepartmentFilter = {
  field: "<value>",
  values: [
    "<value 1>",
    "<value 2>",
  ],
};
```
