# PlatformDurableAgentRun

Agent run state, pending tool approvals, and output available independently of the creation request.

## Example Usage

```typescript
import { PlatformDurableAgentRun } from "@gleanwork/api-client/models/components";

let value: PlatformDurableAgentRun = {
  run_id: "<id>",
  agent_id: "<id>",
  state: "CANCELLING",
  created_at: new Date("2025-12-31T22:33:04.077Z"),
  updated_at: new Date("2025-09-06T14:47:47.909Z"),
  pending_interactions: [],
};
```
