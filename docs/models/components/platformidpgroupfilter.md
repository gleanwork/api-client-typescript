# PlatformIdpGroupFilter

A filter on one IdP group field.

## Example Usage

```typescript
import { PlatformIdpGroupFilter } from "@gleanwork/api-client/models/components";

let value: PlatformIdpGroupFilter = {
  field: "<value>",
  values: [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
};
```
