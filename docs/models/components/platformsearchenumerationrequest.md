# PlatformSearchEnumerationRequest

Selection to enumerate. At least one of `datasources`, `query`, or `filters` must be set.


## Example Usage

```typescript
import { PlatformSearchEnumerationRequest } from "@gleanwork/api-client/models/components";

let value: PlatformSearchEnumerationRequest = {
  query: "amoxicillin",
  datasources: [
    "gdrive",
  ],
  page_size: 500,
};
```
