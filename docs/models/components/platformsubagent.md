# PlatformSubagent

An isolated execution unit that its parent agent dispatches work to. A subagent has no trigger, channels, or subagents of its own, and its dependencies may only reference published skills.


## Example Usage

```typescript
import { PlatformSubagent } from "@gleanwork/api-client/models/components";

let value: PlatformSubagent = {
  name: "HR Policy Agent",
};
```
