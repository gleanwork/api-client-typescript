# PlatformUser

A user in the Glean directory.

## Example Usage

```typescript
import { PlatformUser } from "@gleanwork/api-client/models/components";

let value: PlatformUser = {
  user_id: "<id>",
  display_name: "Norwood.Breitenberg",
  is_active: false,
};
```
