# PlatformUserFilter

A filter on one user field.

## Example Usage

```typescript
import { PlatformUserFilter } from "@gleanwork/api-client/models/components";

let value: PlatformUserFilter = {
  field: "<value>",
  values: [
    "<value 1>",
    "<value 2>",
    "<value 3>",
  ],
};
```
