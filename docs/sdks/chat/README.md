# Chat

## Overview

### Available Operations

* [create](#create) - Create a chat response

## create

Run an assistant turn. Set `stream` to true to receive server-sent events; otherwise the response is a typed JSON response object.


### Example Usage

<!-- UsageSnippet language="typescript" operationID="platform-chat-create" method="post" path="/api/chat" -->
```typescript
import { Glean } from "@gleanwork/api-client";

const glean = new Glean({
  apiToken: process.env["GLEAN_API_TOKEN"] ?? "",
});

async function run() {
  const result = await glean.chat.create({
    input: "What is our parental leave policy?",
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { GleanCore } from "@gleanwork/api-client/core.js";
import { chatCreate } from "@gleanwork/api-client/funcs/chatCreate.js";

// Use `GleanCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const glean = new GleanCore({
  apiToken: process.env["GLEAN_API_TOKEN"] ?? "",
});

async function run() {
  const res = await chatCreate(glean, {
    input: "What is our parental leave policy?",
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("chatCreate failed:", res.error);
  }
}

run();
```
